# Number Guessing Game

**Internship:** Oasis Infobyte – Java Development  
**Task:** Number Guessing Game

## Project description
This is a console-based Java game. The computer selects a random number between 1 and 100. The player keeps guessing until the correct number is entered.

## Features
- Generates a random number between 1 and 100
- Displays “Too High!” or “Too Low!” hints
- Counts the number of attempts
- Maintains a score across rounds
- Allows the player to play again

## Technology
- Java
- Visual Studio Code (or any Java IDE)

## How to run
1. Make sure a Java JDK is installed.
2. Open this folder in VS Code.
3. Open `NumberGuessingGame.java`.
4. Run the file using **Run Java**, or open the VS Code terminal in this folder and execute:

   ```bash
   javac NumberGuessingGame.java
   java NumberGuessingGame
   ```

5. Enter guesses in the terminal. Enter `y` to play another round or `n` to exit.
